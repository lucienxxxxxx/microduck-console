# microduck 改装台

非官方的 MicroDuck 3D 打印配色和贴纸预览。鸭子站在中间，左边改零件颜色，右边把预设贴纸贴到点中的零件上。

界面配色取自 [microduck.net](https://microduck.net/)：墨色、纸色、明黄、橙、粉、青，粗体标题和黑边滚动条。

## 运行

需要 Node.js 18 或更新版本。

```bash
npm install
npm run dev
```

浏览器打开 http://127.0.0.1:5173/

界面规范在 `.cursor/skills/comic-console/`。打开同目录的 `gallery.html` 可以看参考组件。
